# 2026-09-20: truthful call states QA (jes-11)

## Surprises worth keeping

- **Production guest auth needs an HTTPS origin locally.** `next start` + NextAuth
  issues `__Secure-` session cookies, so a plain `http://localhost` QA loop drops the
  session. A small self-signed TLS reverse proxy in front of the app port fixes it.
- **`/explore/[id]` streams, and the AgentCallGate subtree is briefly duplicated**
  (~200 ms, `[role=status]` count goes 0 -> 2 -> 1) before the streamed content
  settles. Playwright assertions must wait for the collapse, yet the localStorage
  mount guard still fires exactly one auto POST.
